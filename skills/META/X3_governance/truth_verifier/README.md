# Truth Verifier

The Truth Verifier is a critical component of Crystal-Clear-OS that ensures all claims are verified against multiple authoritative sources, on-chain oracles, and decentralized consensus. It provides cryptographically attested trust scores with full provenance.

## Features

- Claim verification
- Multi-source cross-checking
- On-chain oracle queries
- ZK proof generation
- Graph RAG aggregation
- Anomaly detection
- Source reputation scoring

## Usage

Initialize the verifier with required clients and call the verify method with a claim.
